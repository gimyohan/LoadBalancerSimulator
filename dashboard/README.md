# 결과 분석 및 시각화 대시보드

데이터 생성기가 만든 이벤트 데이터셋을 웹에서 시각화한다. 시뮬레이션 결과 시각화는 아직 없다.

## 실행

```bash
cd dashboard
npm install
npm run dev        # http://localhost:5173
```

개발 서버는 저장소의 `data/` 디렉터리에 있는 CSV를 자동으로 목록에 올린다.
다른 디렉터리를 쓰려면 `LB_DATA_DIR=/path/to/csvs npm run dev`.
목록에 없는 파일은 **CSV 열기** 버튼이나 드래그 앤 드롭으로 불러온다.
새로 생성한 파일은 **새로고침**을 누르면 목록에 나타난다.

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm test` | 분석 로직 단위 테스트 (Vitest) |
| `npm run build` | 타입 검사 후 `dist/`에 정적 빌드. 정적 빌드에는 `data/` 목록 API가 없어 파일 열기로만 불러온다 |
| `npm run preview` | 빌드 결과를 `data/` 목록 API와 함께 미리 보기 |

## 화면 구성

- **제약 조건 검사**: 세션당 연결/해제 한 쌍, 해제가 연결보다 뒤, 모든 시각이 서로 다름, 가중치 ≥ 1.
  위반 내역을 보여주고, 위반한 행은 집계에서 건너뛴다.
- **요약**: 세션 수, 데이터 기간, 지속 시간(중앙값·평균·p95), 평균/최대 가중치,
  최대 동시 세션 수와 최대 총 가중치(서버 크기를 정할 때 참고).
- **시간에 따른 연결 도착량**: 구간마다 새로 연결된 세션 수.
- **동시 세션 수 / 총 가중치**: 구간 안의 최댓값. 모든 가중치가 1이면 둘이 같으므로 총 가중치 차트는 숨긴다.
- **세션 지속 시간 분포**(로그 간격), **가중치 분포**.

시간축 차트는 확대 범위와 툴팁이 함께 움직인다. 소수의 긴 세션 때문에 데이터 기간이 길게 늘어지면
처음에는 이벤트의 99%가 있는 범위만 보여준다. 전체 범위는 슬라이더로 볼 수 있다.
상단의 **시간 구간**은 시간축 집계 구간 수(100/300/1000)다.

## 구조

```
vite.config.ts        data/ 목록·파일을 제공하는 개발 서버 미들웨어 (/api/datasets)
src/main.ts           데이터셋 목록, 파일 열기/드롭, 화면 전환
src/charts.ts         ECharts 공통 설정 (색은 style.css의 CSS 변수에서 읽음)
src/format.ts         숫자·시간 서식
src/events/
  parse.ts            CSV → 열 단위 typed array, 시각 정렬
  validate.ts         제약 조건 검사 (common/의 lb::validateEvents와 같은 규칙)
  analyze.ts          요약 통계, 시간 구간 집계, 히스토그램
  dataset.ts          파싱·검증·요약을 묶은 데이터셋 로더
  view.ts             이벤트 데이터셋 화면
  events.test.ts      단위 테스트
```

시뮬레이션 결과 시각화는 `src/results/`에 같은 구성(parse/analyze/view)으로 추가하고,
`main.ts`에서 데이터셋 종류에 따라 뷰를 고르게 하면 된다.
