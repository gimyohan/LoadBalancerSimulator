# 결과 분석 및 시각화 대시보드

데이터 생성기가 만든 이벤트 데이터셋과 시뮬레이션 엔진이 만든 결과를 웹에서 시각화한다.
상단 탭으로 두 페이지를 오간다.

## 실행

```bash
cd dashboard
npm install
npm run dev        # http://localhost:5173
```

개발 서버는 저장소의 디렉터리 두 곳을 자동으로 목록에 올린다.

| 페이지 | 읽는 곳 | 바꾸려면 | 목록 밖의 데이터 |
| --- | --- | --- | --- |
| 이벤트 데이터셋 | `data/*.csv` | `LB_DATA_DIR=...` | **CSV 열기** 또는 드래그 앤 드롭 |
| 시뮬레이션 결과 | `results/<데이터셋>/<전략>/` | `LB_RESULTS_DIR=...` | **폴더 열기**로 `results/<데이터셋>` 또는 `results` 폴더 선택 |

새로 만든 데이터는 **새로고침**을 누르면 목록에 나타난다.

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm test` | CSV 파싱과 분석 로직 단위 테스트 (Vitest) |
| `npm run build` | 타입 검사 후 `dist/`에 정적 빌드. 정적 빌드에는 목록 API가 없어 파일/폴더 열기로만 불러온다 |
| `npm run preview` | 빌드 결과를 목록 API와 함께 미리 보기 |

주소에 현재 페이지와 선택이 남는다: `#/events/<데이터셋>`, `#/results/<결과 그룹>/<상세 전략>`.

## 이벤트 데이터셋 페이지

- **제약 조건 검사**: 세션당 연결/해제 한 쌍, 해제가 연결보다 뒤, 모든 시각이 서로 다름, 가중치 ≥ 1.
  위반 내역을 보여주고, 위반한 행은 집계에서 건너뛴다.
- **요약**: 세션 수, 데이터 기간, 지속 시간(중앙값·평균·p95), 평균/최대 가중치,
  최대 동시 세션 수와 최대 총 가중치(서버 크기를 정할 때 참고).
- **시간에 따른 연결 도착량**, **동시 세션 수 / 총 가중치**(구간 안의 최댓값).
  모든 가중치가 1이면 둘이 같으므로 총 가중치 차트는 숨긴다.
- **세션 지속 시간 분포**(로그 간격), **가중치 분포**.

## 시뮬레이션 결과 페이지

한 데이터셋에 여러 전략을 실행한 결과(`results/<데이터셋>/`)를 한 화면에서 비교한다.
전략마다 고정 색이 있고, 위쪽 칩으로 비교에서 빼거나 다시 넣을 수 있다(색은 바뀌지 않는다).
칩에 마우스를 올리거나 포커스하면 엔진이 `summary.csv`에 기록한 전략 설명과 적용된 파라미터를 보여준다.

**전략 비교**
- 지표 표: 수락·거절·위반, 거절률, 평균 이용률, 이용률 분산(시간 평균), 서버별 평균 이용률 분산,
  선택 시간 평균·p99. 열에서 가장 좋은 값은 굵게 표시한다. 행을 누르면 아래 상세가 그 전략으로 바뀐다.
- 거절률, 서버 간 이용률 분산, 서버 선택 시간 막대.
- 서버 간 이용률 분산 추이, 누적 거절(거절 + 위반) 추이. 두 차트는 확대 범위가 함께 움직인다.

**전략 상세**
- 요약 타일, 총 사용량과 총 용량.
- 서버별 이용률 히트맵: 서버 × 시간, 칸마다 그 구간의 최대 이용률.
- 서버별 평균/최대 이용률, 서버 선택 시간 분포(시계 해상도의 배수로 찍힌다).
- 위반 내역(처음 100건).

시간축 차트는 처음에 부하가 실제로 있는 구간만 보여준다(총 사용량이 최댓값의 5% 아래로 내려간 뒤의
긴 꼬리를 뺀다). 전체 범위는 슬라이더로 볼 수 있다.

## 구조

```
vite.config.ts        data/, results/ 목록·파일을 제공하는 개발 서버 미들웨어 (/api/datasets, /api/results)
src/main.ts           앱 셸: 탭, 주소에 따른 페이지 전환, 파일 드롭, 테마 변경
src/page.ts           페이지 인터페이스
src/charts.ts         ECharts 공통 설정 (색은 style.css의 CSS 변수에서 읽음)
src/widgets.ts        타일·패널 HTML, 차트 묶음, 시간축 확대, 히스토그램 차트
src/csv.ts            따옴표를 지원하는 범용 CSV 읽기
src/histogram.ts      로그/값 히스토그램
src/format.ts         숫자·시간 서식
src/events/           이벤트 데이터셋 페이지 (parse, validate, analyze, dataset, view, page)
src/results/          시뮬레이션 결과 페이지
  parse.ts            summary/servers/timeline/assignments/violations CSV
  source.ts           결과 출처(개발 서버, 로컬 폴더)와 데이터셋별 묶음
  analyze.ts          비교 행, 최선값, 이용률 히트맵, 초기 확대 범위
  view.ts             비교·상세 화면
  page.ts             페이지 상태, 로딩과 캐시
```

새 페이지는 `Page`를 구현하고 `main.ts`의 `pages` 목록에 추가하면 탭이 생긴다.
